# v1.0.0 provenance and scope

The creator explicitly approved the complete scene at iteration 258 on 2026-09-21: “we did it! we're done. v1.0.” This supersedes earlier pending-review flags for the retained scene. Historical study records remain historical.

| Released component | Origin and preservation |
| --- | --- |
| Environment, architecture, weathering, lighting and ink | Authored native Blender scene accumulated through 258 studies; editable in the packed scene. Some historical mesh degeneracies remain; no globally clean-topology claim. |
| Cloud layers | Native-derived raster pigment assets from studies 082, 133 and 199, packed in the scene. The finished raster bytes are preserved; earlier 3D cloud masters and the complete research archive are not part of this compact release. |
| Soil pigment | Authored study 094 pigment-C texture, packed; later native material layering retained. |
| Airam and Miranda | User-selected study 214 pixel art, integrated at 217. User-supplied altered personal photographs informed generated character artwork; final selected sprites and placement canvases are preserved. Private source photographs are not included or required. |
| Colosseum direction | Original project artwork OA-COL-001 / UCL-01, creator-confirmed authorship using ChatGPT Images 2.5. The delivered environment is the native geometry/material interpretation, not a projected reference painting. |
| Runtime | Nine project-authored Python modules and explicit render launcher; imports use Python standard library and Blender-bundled modules. Blender itself is a separately licensed third-party application. |

Original source hashes and records are preserved under `releases/v1.0.0/evidence/`. Their old paths refer to the research workspace; final render dependencies are packed. Earlier `user_approved: false` in the 214 provenance record describes that earlier record, not the final approval.

The release allowlist excludes purchased game data, third-party reference collections, personal source photographs, and the old prototype. No public distribution license has been chosen; this capture does not grant a new license. Any Space Quest-specific integration or publishing decision remains separate from completion of this artwork. The historical licensing inquiry is neither permission nor a dependency of rendering the original scene.
