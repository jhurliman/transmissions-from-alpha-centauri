# Project brief

Transmissions from Alpha Centauri is a finished illustrated scene: a ruined city street, two travelers, and a distant Colosseum beneath an orange sky. Editable Blender architecture, weathering, ink and atmosphere are combined with approved pixel-art characters.

The creator approved study 258 as v1.0.0 on 2026-09-21. The public deliverable is the authoritative 4K image, packed editable scene, native render runtime, licenses and reproduction documentation. It is not a playable game or a modification of a commercial game.

Start with the [README](../README.md), [reproduction guide](release/REPRODUCING.md), and [provenance](release/PROVENANCE.md). Software is GPL-3.0-or-later; artwork and documentation are CC-BY-SA-4.0, including commercial reuse under those terms. See [LICENSE](../LICENSE).

The original exploratory brief described a different, abandoned game-integration concept. It is preserved in Git history and the local research archive, not an active roadmap or restriction on this release.
