# Reference observations for distributed face crumbling

UCL01-landmark.png is a crop enlarged from the original project artwork, made by the user with ChatGPT Images 2.5. UCL02-upperwall.png is the user's detail crop. DP03-full.png is a reference-only study by Darius Puia / BakaArts; source and rights remain in references/manifest.json.

The user artwork repeats dark fractured masonry in loosely connected groups around upper openings, cornice/arch shoulders, and pier junctions. Large clusters occupy approximately 15–35% of one bay's width, companions 3–10%. These are visual estimates rather than numerical pixel classifications. Across the visible arcade, approximately one conspicuous cluster per 1–2 bays per level provides rhythm without blanketing every face. Cracks sometimes extend beyond a dark recess; large intact faces remain between them.

Deep arch/interior shadows and dark tower side faces are not evidence of crumbling. Proposed damage changes only shallow wall faces, with actual recess edges and material variation. Existing deep breaches and structural features remain.
