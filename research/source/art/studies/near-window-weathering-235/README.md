# Nearest-right glass: light weathering

Four existing glass panes receive a private native material with four unequal tapered rain traces, a translucent broad stain, and a restrained deposit along the bottom. The original lighting branch remains the source of pane color. No reflected image or painted overlay is added.

Two collection paths are private so the rest of the shared window kit remains unchanged. Pane mesh data, frame objects, placement and all original material bindings remain exact; only the two selected root collection bindings change. The four new pane IDs use object-level material overrides.

`audit.json` records scope; `preservation.json` verifies original state and both private instance paths. The candidate is a CPU study. Final visual acceptance uses the combined native235 render.

Recommended full-resolution review crop: x3470–3840, y0–1220, covering the upper and lower nearest-right windows.

V2 follows the actual combined render: wider unequal tapering trails and greater value separation make the restrained marks legible. The irregular translucent lower fringe rises roughly17–33% of pane height so it survives the existing frame and brace occlusion.
